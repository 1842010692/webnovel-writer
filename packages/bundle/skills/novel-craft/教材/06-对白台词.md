# 对白台词

> 核心定义（《对白》）：对白＝带着特定目的的言语行动。角色一开口，就是在做事；「说」就是「做」。对白有问题，就是故事有问题。

## 台词四核心（编辑老张·台词篇）

写一段对话前，先想清楚这个场景里安排谁说话、让他说话的目的是什么。具体到每个开口的人物，明确四个核心：

1. 当前目的：他现在表面想干啥。
2. 深层欲望：他真正想要什么（常常自己都不承认）。
3. 语言风格：他是谁、怎么说话（身份、性格、文化水平决定词库句式）。
4. 冲突点：他和对方之间未解决的矛盾是什么。

写初稿不纠结文笔（编辑老张）：写初稿最忌讳纠结文笔。按四核心把对话直白地写出来，不加修饰、不管语气节奏，只要把人物想说的话想做的事写清楚就够。润色放到后面。

## 对白的三种功能（每一句至少占一样）

1. 解说（Exposition）：交代背景、历史、角色信息。
   - 准则：化整为零、一点一点释放——只在读者需要知道也想要知道的时机透露，绝不提前，只给少量。
   - 技巧 A（叙事驱动）：借对白泄露信息激发求知欲，读者往前追而不是停下来消化。
   - 技巧 B（如武器般呈现）：让角色用「彼此已知的事实」当武器去争取想要的东西。
   - 反例（讲出来）：「我们认识二十年了吧，从上学起。」
   - 正例（演出来）：「你他妈什么时候才长大？看看这身 T 恤，跟你二十年前在学校那副混球样没区别。」信息藏在攻击里。
2. 角色塑造（Characterization）：创造「表象对真相」。表象是面具，吸引读者想知道面具下是什么；真相是角色被逼到角落、必须做危险抉择时显露的真实自我。
3. 行动（Action）：对白最重要的功能——让角色通过说话达成目的（施压、试探、掩饰、讨好、拒绝）。

## 冰山技巧：已说、未说、不可说

对白内容分三层，决定人物厚度：

- 已说：角色选择讲给人听的心思和感情（露出海平面的冰山一角）。
- 未说：角色内心只对自己说的心思和感情（海面下若隐若现）。
- 不可说：潜意识里的驱动力和欲求，说不出口、连对自己也说不清（深不可知的庞大冰层）。

文本对潜文本：文本是字面说了什么；潜文本是表面之下真正的心思。写好对白＝让读者像通灵一样看穿角色，读者比角色更了解角色自己。一般人说的话绝不完全体现所想所感——真实人生如此，虚构亦然。

由内而外的写作顺序（重要）：先写故事（触发事件、主控思想、冲突），再设计角色与场景，对白是最后一步——先有潜文本，再一层层涂抹文本，就像先写冰山的水下部分，再露出水面一角。

## 对白的六大任务（写后自检）

1. 角色只要开口讲话，就有内在行动。
2. 每一拍的行动、反应都强化该场戏，以转捩点为轴心蓄积能量。
3. 台词里的陈述和影射具有解说功能。
4. 每个角色各有其语言格调（词库、句式、节奏、用字）。
5. 一拍接一拍往前流泄的气势牢牢抓住读者。
6. 语言放在演出背景中恰如其分，符合角色性格，让读者信以为真。

## 常见瑕疵与病灶（诊断表）

| 瑕疵 | 病根 | 药方 |
|---|---|---|
| 浅白露骨（最致命） | 角色把心思和情感直接说出来 | 把潜文本压回水面下；让行动代替宣言 |
| 内容空洞 | 说双方都知道的事 | 删；用行动、潜文本承载信息 |
| 情绪过激 | 台词情绪与实际处境不匹配 | 在潜文本里找理由，或降级情绪 |
| 知道太多 | 作者借角色之口作弊 | 作者与角色划清界限，只给角色「该知道的」 |
| 借口当动机 | 把角色知道的事当动机 | 动机往往角色自己也不自知，作者必须全知 |
| 陈词滥调 | 观众能抢先说出下一句 | 反转预期，给角色专属说法 |
| 笼统无奇 | 谁嘴里都能说出的话 | 具体化，贴角色性格 |
| 铺张卖弄 | 作者炫耀文笔 | 台词服务于角色，不服务于作者 |
| 重复唠叨 | 反复角力但情节无进展 | 重复降低冲突，删到每句都推动节拍 |

## 写对白的七条注意

1. 具体优于抽象：用具体的名词、量词、动作。
2. 熟悉优于奇异：不脱离角色身份故弄玄虚。
3. 短优于长：情绪越激烈、处境越危险，句子越短越直；被动、踌躇、聪明人句子更长更复杂。
4. 直言优于曲笔：曲笔让人听不懂；潜文本让人看懂。
5. 主动优于被动：被动句是文学描述手法，不是日常交流方式。
6. 长话短说优于长篇大论。
7. 删除无意义的枝节：日常寒暄不增加真实感，只掏空场景。

## 冲突承载信息与角色语言格调

- 用冲突承载信息：把背景、情节信息放进对抗性对话里，而非干巴巴的解说。
- 差异化语言：不同角色用不同词库、句式、节奏。考虑人物的教育背景、职业、经济状况——说出「像他的话」。
- 对话张力：不做最后决断、不提供信息、答非所问，本身就是冲突。

## 自检清单

- [ ] 每个开口人物都明确了四核心（当前目的、深层欲望、语言风格、冲突点）
- [ ] 「说出来的」和「真正想的」不一样（潜文本成立）
- [ ] 每场对话至少有一方在回避直接回答（答非所问、反问、转移）
- [ ] 每句台词承担三功能（解说、塑造、行动）至少之一
- [ ] 无闲聊寒暄；删除后情节不变的台词一律删
- [ ] 读出声来像这个角色说的话，而不是作者在说话
- [ ] 初稿先直白写清四核心，文笔润色留到修订阶段
