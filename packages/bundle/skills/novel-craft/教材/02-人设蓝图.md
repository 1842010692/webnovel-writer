# 人设蓝图

> 核心主张（编辑老张讲网文）：写小说要先从人物设定开始。剧情转折、戏剧冲突、场景转换、时间流逝都围绕人物展开；故事主线与主角的目标一致，戏剧冲突与主角的性格和行为密切相关。先写大纲后定人设，后期剧情不符合性格时只能删改或强按着人物走剧情。

## 人设三步法（编辑老张·人设篇）

### 第 1 步 列三个点

把喜欢过的真实人物（演员、爱豆、历史名人）或虚拟人物（纸片人）列出来，取最喜欢的三个点：性格、外貌、人生经历，写在一张纸上。

### 第 2 步 选熟悉特征结合

从中选出熟悉的性格、外貌、经历。第一本书选有参考原型、且了解的人物，比自己凭空想象的好写得多。把几个原型结合，就得到一个崭新的人设。

### 第 3 步 扩展成完整人物（核心）

**丰富性格立体度：主性格＋记忆点性格**

主性格＝选的最熟悉喜欢的性格；记忆点性格＝独属她的特征性格（人物另一面）。

- 例：主性格腹黑毒舌＋记忆点性格软萌善良，人前软萌可爱小白兔、人后心狠手辣黑莲花。

**扩展外貌特征＋理由**

把一个象征性特征移到角色的部位上，并给它一个来历。

- 例：《花千骨》眉间妖神印记是身怀洪荒之力的象征。移到锁骨，变成被仇人种下的血色花钿印记，每个特征都有原因。

**扩展人物经历：梳理前因后果＋替换代表物**

不要直接照搬别人的设定（那叫抄袭）。先梳理某段人物经历的前因后果，找到贯穿其中的代表事物，把它替换成自己的。

- 例：素素被挖双眼跳诛仙台，300 年后以白浅身份重逢。把「眼睛」换成「一本重要的功法秘籍」，替换后整段恩怨可以重写。

**加金手指**

往经历里加热门网文元素：重生、系统、穿越、穿书，故事立刻有爽点。

**加反转**

把已出现的角色、物品都列出来，逐个想反转。

- 例：复仇的女主偏偏拥有佛系躺平系统——只要表现得与世无争、无欲无求就能积攒咸鱼值兑换修为法宝。女主表面佛系摆烂，实际暗中布局，把所有人蒙在鼓里。
- 要求：逻辑自治，每一个反转都能引出一条连串的故事线。

## 身台形表（编辑老张·训练营人设四维）

写人设落地细节时按四维展开：

- 身：身材体型，与身份设定匹配（如武将后裔 7 岁习武、身形挺拔）。
- 台：台词习惯，见 `06-对白台词.md` 的角色语言格调。
- 形：形态动作，标志性小动作、习惯性姿态。
- 表：表情神态，情绪的外化方式（克制型、外放型）。
- 另加心理活动：遇事的第一反应模式（算计型、冲动型、逃避型）。

## 原型选型（《经典人物原型45种》）

> 原型是行为蓝图（重复出现的动机、恐惧、价值观、冲突反应模式），不是身份标签。先选原型，再用它的动机和恐惧追问角色：他在压力下会做什么选择？再给具体历史、环境和矛盾，让他超出原型本身。

### 配角原型：三大类功能

- 朋友：陪主角走旅程、情感支撑、制造亲密冲突。选朋友看「他能给主角带来什么麻烦」，不只是「他是什么人」。
- 对手：与主角目标冲突或价值观对立，制造压力和反转。对手不等于反派，可以是好人之间的立场冲突。
- 象征：承载主题、映照主角内心（最典型是「影子」——映照或夸大主角的弱点与恐惧，逼他直面自己，也常说出别人不敢说的真相）。

### 七大人类动机

选角色核心动机：安全、归属、自尊认可、理解、自我表达等。用法不是贴标签，而是把角色最在乎的东西放进情节路径，让他必须在珍视与恐惧之间二选一。

### 旅程选型（女性、男性旅程）

- 女性旅程（内向探索、挣脱束缚，9 阶段）：完美世界幻象、背叛觉醒、准备旅程、下坠穿过审判之门、风暴之眼、死亡一切尽失、支持、重生真相时刻、回归完美世界。
- 男性旅程（外在征服加内在抉择，9 阶段）：完美世界、朋友与敌人、召唤、小胜、邀请、考验、死亡岔路口、觉醒或反叛、胜利或失败。
- 旅程可跨性别使用，是向导不是牢笼。网文实操：重生、逆袭文天然贴合男性旅程的「召唤、考验、觉醒」；救赎、虐恋文贴合女性旅程的「背叛、下坠、重生」。

## 配角五大功能（编辑老张·大纲篇）

配角一个萝卜一个坑，按功能分配：

1. 推动型：给线索、拉仇恨（例：苏培盛、槿汐）。
2. 对照型：与主角做选择上的对比（例：安陵容对照甄嬛）。
3. 情感型：渲染情绪、逼主角成长（例：沈眉庄）。
4. 调节型：调节节奏、制造缓冲（例：淳儿）。
5. 功能型：纯过剧情的小太监小宫女，不占塑造资源。

## 人物关系表与出场顺序（编辑老张·大纲篇）

- 人物关系表：谁是敌、谁是友、谁和谁利益牵扯，列清楚。例：甄嬛对皇帝前期夫妻后期仇人；对皇后死敌；对沈眉庄生死之交。关系明了就不会写着写着逻辑混乱。
- 出场顺序表：重要角色按出场先后列个大概顺序，避免「第三回死的人第五回又出来」的低级错误。

## AI 邪修大法（编辑老张·主线篇）

把角色大致人设告诉 AI，问「这个角色会有什么目标」——AI 会生成错误的理解。在纠正它的过程中，主角的目标、欲望甚至形象会越来越清晰。目标即路线图的终点站。

## 自检清单

- [ ] 主角有「主性格＋记忆点性格」，人前人后存在反差
- [ ] 每个优点配了一个阴影版本（能成为可信威胁），反派恶与主角善同根
- [ ] 每个外貌特征都有来历（被谁、因何事留下）
- [ ] 人物经历是「梳理前因后果＋替换代表物」得到的，没有照搬
- [ ] 金手指与反转（如有）逻辑自治，且每条反转都能引出故事线
- [ ] 配角各自承担五大功能之一，没有凑数角色
- [ ] 人物关系表、出场顺序表已列出，主线目标与主角欲望一致
