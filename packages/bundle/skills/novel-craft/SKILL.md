# 五书网文教科书（Novel Craft）

本技能是写作技法参考手册，不是节点流程。主控在立项、设计、起草、审读或修改阶段需要方法论时，按下面路由读取对应教材；教材内容只作建议与检查清单，未获作者采纳的建议不写成已确认设定。

## 教材路由

| 教材 | 何时读 | 主要来源 |
| --- | --- | --- |
| `教材/01-题材与书名.md` | 立项阶段定题材、定基调、取书名、写简介 | 编辑老张讲网文·题材篇、书名篇 |
| `教材/02-人设蓝图.md` | 设计角色、人物关系、人物弧光 | 编辑老张讲网文·人设篇；人物原型45种 |
| `教材/03-大纲结构.md` | 写大纲、防跑纲、规划长篇 | 编辑老张讲网文·大纲篇；雪花写作法；救猫咪 |
| `教材/04-黄金三章与开篇.md` | 写开篇、首秀起量、申签咨询 | 编辑老张讲网文·开篇系列；冲突与悬念 |
| `教材/05-冲突悬念与断章.md` | 情节平淡、不抓人、断章留人、写长不注水 | 冲突与悬念；编辑老张讲网文·主线篇、拆书篇 |
| `教材/06-对白台词.md` | 写对话、对白很假、没张力 | 对白；编辑老张讲网文·台词篇 |
| `教材/07-修订与码字.md` | 卡文、修订自检、查水字数 | 编辑老张讲网文·卡文篇；五书体检清单 |

## 使用边界

- 只提供方法论与检查清单，不替代《工作台总控》的节点路由与专用工具。
- 建议一律标明来源：五书方法论是公开整理，老张打法是公开教程整理。不属于原书内容的判断标「扩展建议」。
- 不虚构书中或视频中不存在的步骤。
- 涉及签约、首秀、追读等数据指标时，按作者实际投稿平台适配，不给平台承诺。
- 与节点技能衔接：定调设计阶段取 `教材/01`、`教材/02`、`教材/03`；正文起草阶段取 `教材/04`；全面审读与精修润色阶段取 `教材/05`、`教材/06`、`教材/07`。

## 完成标志

主控读完所需教材，向作者输出对应检查清单的结论与建议稿。

## Off-limits

- 不派发子代理读取教材，主控按需读取。
- 不把教材方法自动升级为硬约束；作者未采纳的建议不写入契约、世界书或大纲。
